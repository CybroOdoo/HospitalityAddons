Hospitality Management - Reservation
====================================
* This module provides reservation management for the Hospitality Management
  suite. It enables reservation creation and lifecycle management, room
  availability checking, reservation groups, room assignment, front office
  operations, guest sharing, and interactive tape chart scheduling. It also
  includes property-based security, reservation workflows, availability
  validation, and hospitality dashboards for reservation management.
