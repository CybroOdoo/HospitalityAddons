Hospitality Management - Maintenance
====================================
* This module provides maintenance management for the Hospitality Management
  suite. It enables hospitality asset management, preventive maintenance (PPM)
  templates, corrective maintenance work orders, maintenance groups, work order
  aging analysis, and scheduled preventive maintenance generation. It also
  integrates with Odoo's Maintenance application, providing property-based
  maintenance operations, automated maintenance scheduling, and asset lifecycle
  tracking.

=============
