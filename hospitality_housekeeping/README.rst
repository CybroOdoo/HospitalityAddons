Hospitality Management - Housekeeping
=====================================
* This module provides housekeeping operations for the Hospitality Management
  suite. It enables room status management, housekeeping task assignment,
  attendant scheduling, supervisor inspection workflows, discrepancy tracking,
  Do Not Disturb (DND) management, linen count management, and lost & found
  tracking. It also includes property-based security, housekeeping reports,
  scheduled housekeeping processes, and operational dashboards for efficient
  housekeeping management.
