Before you install

Frequent questions

The things people ask us most often about the suite.

Do I need every module in the suite?

No. hospitality_base is the foundation and the rest sit on top of it. Install only the areas you run - front desk, housekeeping, folios, rates, maintenance, booking engine - and add the others later.

Does it work on Odoo Community?

Yes. The suite is built for Odoo 19 and runs on both Community and Enterprise. Nothing in it depends on an Enterprise-only module.

Can one database run several properties?

Yes. Properties are first-class records with their own currency, timezone, sequences and business date, and users are bound to the properties they are allowed to operate in.

Does the booking engine need a payment provider?

Checkout lists whatever payment providers you have enabled in Odoo. Searching, pricing and availability all work before any provider is configured, so you can evaluate the flow first.

Will it change how my other Odoo apps look?

No. The included theme styles the login, the app drawer and the navbar only. Form views, list views, buttons, modals, Discuss and the Chatter keep Odoo's own styling.
