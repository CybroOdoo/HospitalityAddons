# Demo images

Photographs used by the suite's demo data for properties and room types.

Source: Unsplash (https://unsplash.com), used under the Unsplash License,
which permits commercial use and redistribution and requires no attribution.
Only free-licence photos are included - no Unsplash+ material.

Photos showing an identifiable hotel's name or branding were deliberately
excluded, so no demo record implies an affiliation with a real business.

These files are referenced from the demo data of several modules via
`<field name="..." type="base64" file="hospitality_base/static/src/img/demo/..."/>`.
To use your own photography, replace a file keeping its name - no XML change
is needed. A 3:2 crop matches the kanban image frame.
