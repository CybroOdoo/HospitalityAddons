Hospitality Management - Base
=============================
* This module provides the core foundation for the Hospitality Management suite in Odoo.
  It includes property and brand management, user and company property mapping,
  market segments, source codes, transaction codes, cancellation and deposit
  policies, activity tracing, property-based access control, business date
  management, encrypted field support, automatic sequence generation, and a
  Property Switcher for multi-property environments.

Configuration
=============
* No additional configurations needed.
