Hospitality Management - Booking Engine
=======================================
* This module provides a public-facing online booking engine for the
  Hospitality Management suite. It enables guests to search room availability,
  browse rates, make online reservations, apply promotional codes, select
  upsell services, and complete bookings through integrated payment providers.
  It also includes booking engine configuration, website integration, search
  session management, scheduled cleanup, email notifications, and role-based
  access for booking engine administration.
