Hospitality Management - Guest Profile
======================================
* This module provides guest profile management for the Hospitality Management
  suite. It extends Odoo Contacts with hospitality-specific guest information,
  including guest preferences, dietary requirements, identification documents,
  guest history, and secure management of personally identifiable information
  (PII). It also includes role-based access control, PII audit logging, guest
  data sequences, and Right to Be Forgotten (RTBF) support.
